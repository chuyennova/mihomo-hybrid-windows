Not claimed locally
-------------------
A full end-to-end Go build was not executed in this container because its local
Go is 1.23.2 while the frozen successful V1 graph requires Go >=1.25 and this
runtime cannot reliably download a newer toolchain/module graph. The supplied
GitHub Actions workflow uses the MetaCubeX Go 1.26 toolchain and performs the
actual vendor, executable regression tests, Windows cross-compile, full binary
compile, Wintun packaging and final quality gate.

Runtime packet capture remains the final proof of wire-visible IPv6 behavior.
The CI audit proves code-path selection and deterministic algorithm properties;
it cannot observe changes made later by a WireGuard peer, NAT, router or ISP.
